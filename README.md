


# Mein PC

Dies ist ein kleines Übungsprojekt für eine moderne, responsive Website zum Thema „Mein PC“.

## Überblick

Die Webseite wurde nach aktuellen Webstandards aufgebaut und nutzt semantisches HTML5 sowie ein responsives Layout, damit sie auf Desktop-, Tablet- und Mobilgeräten gut dargestellt wird.

## Inhalte der Seite

- Vorstellung der PC-Komponenten
- Informationen zu Lerninhalten und verwendeten Dokumentationen
- Übersicht der genutzten Software
- Responsive Gestaltung für verschiedene Bildschirmgrößen

## Technologien

- HTML5
- CSS3
- Responsive Webdesign

## So startest du das Projekt

1. Klone oder lade das Projekt herunter.
2. Öffne die Datei `index.html` in deinem Browser.

## Ziel des Projekts

Das Projekt soll die Grundlagen von modernem Webdesign sowie die Umsetzung einer strukturierten und benutzerfreundlichen Webseite üben.
